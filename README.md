# pb-plans

Hébergement des plans de développement individuel ProBreakthrough.

- Un fichier HTML par athlète, nommé avec un identifiant opaque (pas de nom d'enfant dans l'adresse).
- Chaque page contient une balise `noindex` et le dépôt sert un `robots.txt` qui bloque tous les robots d'indexation.
- Les liens ne sont pas secrets : ils sont non répertoriés et non indexés. Toute personne à qui le lien est transmis peut ouvrir la page.
- **Aucune donnée médicale ou scolaire.** Ni diagnostic, ni intervention, ni nom de clinicien, ni nom de clinique, ni rendez-vous médical. Un plan de retour au jeu se rédige en renvoyant à « tes directives écrites », sans dire d'où elles viennent. Le contexte médical passe par courriel, qui est privé.
- Pour retirer un plan, supprimer le fichier. Le lien cesse de fonctionner immédiatement.

## Avant de publier

Passer le fichier au filtre : `maheu`, `physio`, `chirurgie`, `orthopéd`, `ligament`, `cicatris`, `clinique`, `diagnostic`, `rééducation`, le nom complet de l'athlète. Zéro occurrence attendue.
